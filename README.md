# Excel Cleaner

أداة Python بتنضف ملفات Excel الوسخة وتطلعها جاهزة للاستخدام.

## بتعمل إيه؟
- بتشيل المسافات الزيادة من الأسماء
- بتحذف الصفوف المكررة
- بتوحد صيغة أرقام التليفون (010-1234-5678)
- بتوحد صيغة التواريخ (2024-01-15)
- بتنضف المبالغ من الرموز والنصوص
- بتتعرف على أسماء أعمدة مختلفة (التليفون / الموبايل / الهاتف)
- بتحفظ الصفوف المحذوفة في ملف منفصل
- بتكتب تقرير بكل اللي اتعمل

## إزاي تستخدمها؟
1. نزل المكتبات: `pip install pandas openpyxl`
2. شغل: `python clean_clients.py`
3. اكتب اسم ملف Excel بتاعك

## تواصل معايا
لو عندك ملف محتاج تنضيف، كلمني على مستقل.
